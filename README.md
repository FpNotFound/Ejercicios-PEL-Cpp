# Ejercicios PEL - C++

Repositorio con los ejercicios realizados para la asignatura **Programación con Estructuras Lineales (PEL)**.

## Descripción

En este repositorio se encuentran diferentes ejercicios desarrollados en **C++**, utilizando conceptos de programación orientada a objetos, clases, herencia, plantillas y estructuras de datos.

## Ejercicios

### Ejercicio 1
Implementación de una clase `FiguraGeometrica` y diferentes figuras derivadas, como círculos, triángulos y rectángulos. Se calculan sus áreas y perímetros.

### Ejercicio 2
Implementación de las clases `Estudiante` y `RegistroEstudiantes`, incluyendo el registro de estudiantes, cálculo de promedios y visualización de información.

### Ejercicio 3
Implementación de una clase `CuentaBancaria` con operaciones para depositar, retirar dinero y consultar el saldo.

### Ejercicio 4
Implementación de plantillas de funciones (`templates`) para obtener el valor máximo y mínimo entre dos valores.

### Ejercicio 5
Implementación de una plantilla genérica para intercambiar dos valores del mismo tipo.

### Ejercicio 6
Implementación de una lista genérica utilizando plantillas, capaz de trabajar con diferentes tipos de datos. Incluye operaciones para agregar, eliminar, buscar y ordenar elementos.

### Ejercicio 7
Implementación de una matriz genérica utilizando plantillas. Incluye inicialización, visualización, suma y multiplicación de matrices.

## Tecnologías utilizadas

- C++20
